✈️ Skylink (Aviation Winds Aloft)
RapidAPI Key
Optional — adds aviation-grade winds aloft at 9 standard altitudes. Free tier: 1,000 requests/month at rapidapi.com. Stored locally on your device only. Falls back to the free Open-Meteo / NOMADS chain on any error.
⚡ Lightning (WarPulse)
WarPulse API Key
Optional — real-time lightning strikes from lightning.warpulse.com. Stored locally on your device only — never sent anywhere except WarPulse (relayed through the StormTracker proxy, which doesn't store it). With a key, real observed strikes appear on the map and sonar; without one, lightning is estimated from radar (cells ≥ 48 dBZ).
